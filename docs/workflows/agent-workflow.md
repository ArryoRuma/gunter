# Agent Workflow

## Serious feature workflow

1. Product strategist
2. Architect
3. Implementer
4. Test engineer
5. Reviewer
6. DevOps engineer, if deployment or CI is affected

## Bug workflow

1. Debugger
2. Implementer
3. Test engineer
4. Reviewer

## UI workflow

1. UI engineer
2. Frontend reviewer
3. Performance engineer, if needed

## Repo setup workflow

1. Product strategist
2. Architect
3. Repo scaffolder
4. DevOps engineer
5. Reviewer

## Rules

- Start with an issue.
- Ask for a plan before implementation.
- Keep diffs small.
- Validate before merging.
- Document meaningful behavior changes.
